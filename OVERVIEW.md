Recent Chats is a triage inbox for your chats. It answers one question: what should I look at next?

The sidebar list has two views, chosen in its first row. Projects, the default on wide screens, shows a Needs you strip, a Pinned section and a tree of host, project, workspace and chat, with each workspace's branch, whether it is a checkout or a worktree, its line changes, and its newest three chats. Triage, the default on phones, is the list described below. A project, a workspace or a chat can be pinned; the Pinned section shows each pinned item with its parents and everything below it, and pins are the same on every device. The search button filters the view in place, and the Hosts dropdown switches hosts on or off and grouping by host. Grouped by host, the hosts can be put in order: drag a host's grip in the Projects view, or use the up and down arrows on its heading in Triage; the order is the same on every device and in both views. Projects, workspaces and hosts can be dragged in the Pinned section as well; it shares its order with the tree. The “Empty” cleanup filter above the tree lists only workspaces without chats (archived chats do not count) and projects without workspaces, so they can be archived; like “Stale” it hides Needs you and Pinned, and the two filters exclude each other (projects without workspaces need an app that gives plugins the project list). The “Last N days” filter above the tree hides workspaces with nothing newer than the inactive window (Settings, Sections, Inactive, Window; 14 days by default). Next to it, the “Stale” filter is a cleanup helper: it shows only chats nothing has happened in for longer than the stale age (Settings, Projects view; 30 days by default), without the Needs you box and the Pinned section, so they can be archived from their ⋮ menus. Project names are in capitals. A project or workspace name is white while something happens in it (running, asking you, or finished and unseen) and grey otherwise, like its chats. Drag a project by its folder icon, or a workspace by the grip before its name, to reorder them (on a touch screen, hold the icon a moment first, so a swipe over it still scrolls); the others glide out of the way while you drag, and the order is the same on every device. A workspace folds with its chevron or a click on its name. Three icons above the tree, and in the Pinned heading for the Pinned section, collapse every project, expand everything, or fold everything and then open only the projects and workspaces where something happens; resting the pointer on one shows what it does. Text in the list follows the interface font size set in Paseo (Settings, Appearance) on web and desktop. Settings, Projects view chooses what the tree shows: the branch (optionally not when it is main or master), checkout or worktree, line changes, the host tag on projects, and each chat's age and agent.

It lists chats from every connected host as one row each. By default a row shows the host (in the colour you gave it in Paseo), a status symbol, the project and workspace names cut to 10 characters each and the chat title, with the git branch and the agent's model on a second line. Rest the pointer on a row for a moment, or long-press it on a touch screen, to see a card with the full title, project and workspace, and the agent with the branch on the right; the agent shows its harness icon as in Paseo, in rows and in the card; the card can be switched off and made more transparent in the settings. Sub-agents are not listed, except one that asks you a question or for a permission: it shows under its parent chat, which then waits for you too (in Needs you and in the tree). Back and forward arrows in the Recent Chats sidebar row go through the chats you had open, like a browser's history (kept until the app restarts). Rows are ordered by what needs you most: unread chats oldest first, then running chats oldest first, then the most recently used inactive chats; the order of the sections and the direction inside each can be changed in the settings. Each group has a size limit, and chips show how many more are hidden. A chevron on the Pinned, Running and Inactive headings, and on each host heading when rows are grouped by host, folds that group away; this lasts until the app restarts and is not a setting. The chat open on screen has a faint accent background while its Inbox or Later pill is shown. Every project, workspace and chat has a ⋮ menu, like Paseo's own sidebar: right-click or long press open it too. A pin button shows only on pinned items; pinning is in the menu. Each menu holds what belongs to its item: a host's Mark all chats read, Collapse its projects, Hide this host and Copy host name; a project's New workspace; a workspace's Open workspace, Rename, Copy path and branch, and Archive; a chat's Open, and outside the tree Open workspace. In the Paseo 0.16 sidebar view New workspace opens Paseo's own new-workspace flow; in the sidebar item it creates a worktree off the project's default branch and opens it. A menu opens above its row when there is no room below. Buttons show only where they apply; on a chat, unpin comes before read or Later. In the Projects view a folder-plus button in the first row adds a project: pick the host and type the folder on it (plugins cannot show a folder picker); Paseo opens it as a workspace. It holds open, new workspace (on projects and workspaces) and open workspace (in the Paseo 0.16 sidebar view), rename (saved on the item's own host, which needs Recent Chats installed), pin, mark read or unread, collapse, reload a chat's session, copy path, branch name, project name or title, and archive, which asks first when something is still running. Status symbols use Paseo's own colours: Paseo's turning blue ring while a chat runs; a slowly pulsing amber "?" when it asks you something (a question or permission request, also while it runs); a green tick when it finished and you have not looked yet (bold while the agent is still in memory, thin once Paseo has released it); a red warning triangle when it failed (filled while in memory, outlined once released). An inactive chat shows how it last ended, in grey. A waiting chat you open keeps its place, with a grey symbol, until you open another chat or its state changes.

Search filters the list by fuzzy match across title, project, workspace, branch, agent and host. A cog next to the list opens the settings. Open it from the sidebar, from the Inbox pill next to the composer, or from the Command Center. The Later pill, or Alt+L, sets the chat you are in aside as unread; the pill then reads Read, and pressing it again takes the chat off the list. Alt+Shift+1 to 9 open the first to ninth chat of Needs you (Alt+1 to 9 are Paseo's own tab keys). By default you stay on the chat; “After Later” can open the next one instead. Opening a chat that waits for you, from a list or by going back and forward (arrows, mouse buttons, Alt+← / Alt+→), does not mark it read: it stays in Needs you until you type in it or click into its messages, so you can look through chats without losing track of them. Once read, it keeps its place in Needs you, grey, until another chat is open. On desktop the mouse's back and forward buttons and Alt+← / Alt+→ step through the chats you had open, like the arrows (Alt+arrows are left to a terminal, and on a Mac to text fields, where they move by word). Alt+↑ / Alt+↓ jump to your previous or next message in the chat on screen, like a press on Paseo's chat outline at the right edge, and from the newest one scroll to the very end (desktop and web; it reads what Paseo draws, so a Paseo update can stop it). On phones a row shows its project and workspace on a second line, and a swipe left marks a waiting chat read, a swipe right sends an inactive one to Later (both are in the ⋮ menu too). Button sizes follow the input: a finger gets larger targets, a mouse or trackpad smaller ones, whatever the window width. A line under the filters says how many workspaces “Last N days” hides, and one under the first row which hosts are switched off, each with a link to show them; quiet projects fold like a project row. A Host pill (off by default, switched on in the settings) shows the host the chat runs on, with its icon in the colour you gave the host in Paseo. A pin button on every row keeps a chat at the top, in a Pinned section, whatever its state (a pinned chat still shows its own light, ignores the list limits and the inactive window, and stays until you unpin it). A check button on an unread row marks it read without opening it, a clock button on an inactive row marks it unread (Later), and "Mark all read" clears the whole backlog.

## How unread works

A chat is unread when Paseo flags it as needing attention (finished, failed or waiting for a permission) and you have not opened or dismissed it since. A running chat that is waiting for a permission counts as unread. Unread chats waiting longer than the expiry (7 days by default) fall back to inactive. Chats you mark with Later stay unread until you open them again.

Paseo does not let plugins change its own read state, so Later and "mark read without opening" are stored by the plugin, on the host the chat belongs to. They are not reflected by Paseo's own status indicators.

## Settings

The settings screen has four tabs: List, Projects, Sidebar & pills, and Version & help. On wide windows the List and Projects tabs keep a preview beside the options, with a Desktop / Phone switch; options that only matter while another switch is on are dimmed while it is off, and each of the first three tabs can be reset to its defaults (a second press confirms). The settings are saved on every connected host that runs the plugin, so your phone, your laptop and every host show the same view; the most recently changed copy wins when a host was offline. The settings screen runs from most to least used. Version: the installed version, Check now (asks every host to update) and the switch for automatic updates. This device: which view the sidebar shows (Automatic, Projects or Triage) and the “Last N days” filter of the Projects view; these two are kept per device. Row layout: one layout for the chat rows of both views. Each item (host, status light, project, workspace, tab name, branch, agent name, and age, which is off by default and shows how long ago a chat started waiting, started its turn or had its last message) can be switched on or off, dragged (or moved with arrow buttons) to any position on any line, put on a line of its own, and given its own length in characters (0 means unlimited); changes apply after Save, and the previews follow every edit. Both views: how many Needs you chats are shown, when an unanswered chat expires, and the inactive window. Projects view: a live preview of the tree with the row layout being edited, grouping by host, chats per workspace, and what the tree shows (branch, also main and master, checkout or worktree, line changes, host tag, age, agent). Triage view: grouping by host (the list limits then apply per host), section headings, and the order of the Pinned, Needs you, Running and Inactive sections with each one's sort direction and size. Then which hosts are listed, the sidebar list (expanded, height on phones and on wide screens), the full-names card and its transparency, and the Inbox, Later and Host pills: each switched on or off, and put in order with the arrows (their place among the pills of Paseo and other plugins is Paseo's). Diagnostics: creates a report of the hosts, their status, chat counts, settings and errors (no chat titles, messages or paths), copies it and shows it to select, for a bug report. A host switched off in the host filter is listed again when it is the only one connected, since the filter only shows with two or more hosts.

## Requirements and limits

Needs Paseo 0.14.0 or later on the daemon and the app. On Paseo 0.16 or later phones show only the Recent Chats row in the sidebar, which opens the full list (Projects and Triage) as a screen, because Paseo's phone drawer leaves its rows too little room for a list. On Paseo 0.16 or later Recent Chats can also be the whole sidebar (Settings, Sidebar, Sidebar view): the same list fills the sidebar, follows the chat Paseo has open, and the item in the sidebar's header steps aside; older apps keep the item. Every host that installed it from GitHub keeps it up to date by itself: a few minutes after start and every 6 hours it runs that host's `paseo plugin update` and installs a newer version (switch off under Updates in the settings); once one host has a newer version, the others follow within about a minute while a Paseo app is open. Install it on every host you connect to: each host's copy keeps the pins and read marks of that host's chats, and a copy of the view settings, so every device shows the same. The plugin reads chats and workspaces from each connected host and sends nothing elsewhere. Host colours are read from the app's saved host list, so they show on web and desktop only; on phones the host tag is neutral. Keyboard shortcuts are not available because plugins cannot register them.
