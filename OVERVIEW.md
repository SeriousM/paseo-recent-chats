Recent Chats is a triage inbox for your chats. It answers one question: what should I look at next?

The sidebar list has two views, chosen in its first row. Projects, the default on wide screens, shows a Needs you strip, a Pinned section and a tree of host, project, workspace and chat, with each workspace's branch, whether it is a checkout or a worktree, its line changes, and its newest three chats. Triage, the default on phones, is the list described below. A project, a workspace or a chat can be pinned; the Pinned section shows each pinned item with its parents and everything below it, and pins are the same on every device. The search button filters the view in place, and the Hosts dropdown switches hosts on or off and grouping by host. Active only hides workspaces with nothing inside the inactive window. Project names are in capitals. A project or workspace name is white while something happens in it (running, asking you, or finished and unseen) and grey otherwise, like its chats. Drag a project by its folder icon to reorder the projects; the order is the same on every device. Text in the list follows the interface font size set in Paseo (Settings, Appearance) on web and desktop. Settings, Projects view chooses what the tree shows: the branch (optionally not when it is main or master), checkout or worktree, line changes, the workspace's status symbol, the host tag on projects, and each chat's age and agent.

It lists chats from every connected host as one row each. By default a row shows the host (in the colour you gave it in Paseo), a status symbol, the project and workspace names cut to 10 characters each and the chat title, with the git branch and the agent's model on a second line. Hover a row, or long-press it on a touch screen, to see the full names; the card can be switched off and made more transparent in the settings. Sub-agents are not listed. Rows are ordered by what needs you most: unread chats oldest first, then running chats oldest first, then the most recently used inactive chats; the order of the sections and the direction inside each can be changed in the settings. Each group has a size limit, and chips show how many more are hidden. A chevron on the Pinned, Running and Inactive headings, and on each host heading when rows are grouped by host, folds that group away; this lasts until the app restarts and is not a setting. The chat open on screen has a faint accent background while its Inbox or Later pill is shown. Long press a row (double-click on desktop and web) to rename the chat in place; the title is set on the chat's own host, which needs Recent Chats installed. On touch screens long press therefore no longer opens the full names card. Status symbols use Paseo's own colours: Paseo's turning blue ring while a chat runs; a slowly pulsing amber "?" when it asks you something (a question or permission request, also while it runs); a green tick when it finished and you have not looked yet (bold while the agent is still in memory, thin once Paseo has released it); a red warning triangle when it failed (filled while in memory, outlined once released). An inactive chat shows how it last ended, in grey. A waiting chat you open keeps its place, with a grey symbol, until you open another chat or its state changes.

Search filters the list by fuzzy match across title, project, workspace, branch, agent and host. A cog next to the list opens the settings. Open it from the sidebar, from the Inbox pill next to the composer, or from the Command Center. Opening a chat marks it read. The Later pill marks the chat you are in as unread and opens the next one in the list. A pin button on every row keeps a chat at the top, in a Pinned section, whatever its state (a pinned chat still shows its own light, ignores the list limits and the inactive window, and stays until you unpin it). A check button on an unread row marks it read without opening it, a clock button on an inactive row marks it unread (Later), and "Mark all read" clears the whole backlog.

## How unread works

A chat is unread when Paseo flags it as needing attention (finished, failed or waiting for a permission) and you have not opened or dismissed it since. A running chat that is waiting for a permission counts as unread. Unread chats waiting longer than the expiry (7 days by default) fall back to inactive. Chats you mark with Later stay unread until you open them again.

Paseo does not let plugins change its own read state, so Later and "mark read without opening" are stored by the plugin, on the host the chat belongs to. They are not reflected by Paseo's own status indicators.

## Settings

The settings are saved on every connected host that runs the plugin, so your phone, your laptop and every host show the same view; the most recently changed copy wins when a host was offline. Settings, Recent Chats starts with the row layout. Each item (host, status light, project, workspace, tab name, branch, agent name, and age, which is off by default and shows how long ago a chat started waiting, started its turn or had its last message) can be switched on or off, dragged (or moved with arrow buttons) to any position on any line, put on a line of its own, and given its own length in characters (0 means unlimited). A row can have as many lines as you like. Layout changes apply after you press Save. A live preview above the editor shows every change. "Group rows by host" shows one heading per host and applies the list limits to each host separately. When two or more hosts are connected, a chip per host in the list switches that host's chats on or off; all hosts start on. The rest: how many unread, running and inactive chats are shown, how old an inactive chat can be, the unread expiry, the order of the Pinned, Needs you, Running and Inactive sections (dragged or moved with up and down arrows), whether each lists its chats oldest or newest first (also switched by tapping the sort icon in the section's heading), and each section's size settings, group headings, whether the sidebar list is expanded (opening or closing it in the sidebar is remembered), how much of the window height the sidebar list takes, also when fewer chats would fit (separately for phones and wide screens; dragging the grip under the list sets it too), the Inbox and Later pills, and whether Later opens the next chat or stays put.

## Requirements and limits

Needs Paseo 0.14.0 or later on the daemon and the app. Every host that installed it from GitHub keeps it up to date by itself: a few minutes after start and every 6 hours it runs that host's `paseo plugin update` and installs a newer version (switch off under Updates in the settings); once one host has a newer version, the others follow within about a minute while a Paseo app is open. Install it on every host you connect to: each host's copy keeps the pins and read marks of that host's chats, and a copy of the view settings, so every device shows the same. The plugin reads chats and workspaces from each connected host and sends nothing elsewhere. Host colours are read from the app's saved host list, so they show on web and desktop only; on phones the host tag is neutral. Keyboard shortcuts are not available because plugins cannot register them.
