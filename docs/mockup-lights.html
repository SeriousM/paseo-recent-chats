Lights: agent in memory vs. released

A: dot = loaded, ring = released

A filled dot means the agent is still loaded. A ring of the same colour, not spinning and with no gap, means Paseo has released it (status closed). Running and asking chats keep the spinning ring with a gap; they are never released.

A2: symbols instead of dots

Running shows Paseo's own running mark from the session tabs: a 6 px blue dot inside a ring (1.5 px gap, 1.5 px line) whose faint track carries a brighter quarter turning once every 0.9 s. A chat waiting for an answer (a question or a permission request) shows a slowly pulsing "?". Done is a check, failed a warning triangle. Filled while the agent is loaded, outlined once Paseo has released it, as in A. An inactive chat shows the symbol of how it last ended, in grey. Every symbol sits in a 16 px slot so the titles stay aligned.

B: ring = loaded, dim dot = released

A ring means the agent is open (loaded), like the spinning ring of a working one, only still. A dimmed filled dot means Paseo has released it. Since most chats are released, most rows get the quiet dim dot; a ring stands out as "still open".
