Settings for both views

The settings screen still describes only the Triage list. This mockup regroups it around the two views and orders the sections from most to least used. Badges mark new and moved sections.

Screen:

Order: most used first

  1. Version: this host's installed version, each host's version, Check now (with a result per host) and the auto-update switch. Was "Updates" near the end.
  2. This device (not synced): which view, and Active only. The same state as the sidebar's first row.
  3. Row layout: the preview switches between Triage and Projects. Items the tree shows itself are marked "not in tree".
  4. Both views: the three settings both views use, shown once. Each hint says what it does in Triage and in Projects.
  5. Projects view: group by host, and chats per workspace (now a setting, fixed at 3 today).
  6. Triage view: group by host, section headings, and the Sections card without the settings that moved to Both views.
  7. Hosts: which hosts are listed (also in the Hosts dropdown), and where the settings are saved (was the screen's first line).
  8. Sidebar list: expanded, and the two heights (the grip sets them too). These were under Display.
  9. Full names card, Composer pills: no change.
