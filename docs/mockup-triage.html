How it behaves

  • Row: host, LED, workspace (10 chars, ellipsis), chat title (ellipsis when it does not fit).
  • Opening a chat marks it read, so it drops to inactive (or stays running if it still runs).
  • "Later" marks the chat you are in as unread and jumps to the next item (the top row).
  • Check button on an unread row = mark read without opening. "Mark all read" clears the backlog.
  • Caps per group are a setting (default 6 / 3 / 4). Hidden items show as +N chips that open the full list.
  • Host tag disappears when only one host is connected.

Reachability

  • Inbox pill: inside every chat, shows live counts, popup on desktop, bottom sheet on mobile.
  • Sidebar list on desktop: always visible, collapsible.
  • Full list screen with search for everything beyond the caps.
  • Targets are at least 40 px tall on mobile. No hotkeys in this version.
