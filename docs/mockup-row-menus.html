A ⋮ menu on every project, workspace and chat

In the 0.16 sidebar view Recent Chats replaces Paseo's own list, so the actions of Paseo's row menus should be there too. Each row gets a vertical three-dot button at its right end: shown while the pointer is on the row (always shown on touch screens), and right-click or long press opens the same menu. The pin button stays where it is; the menu holds everything else.
